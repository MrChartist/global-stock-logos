# Code of Conduct

This project welcomes contributors of every background and experience level.

## Our standard

- Be respectful, patient and constructive.
- Give and accept feedback politely. Criticise work, not people.
- Do not harass, insult, discriminate or share private information.
- Keep discussions on topic: logos, data and code in this repository.

## Enforcement

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block repeat offenders. To report a problem, write to [contact@mrchartist.com](mailto:contact@mrchartist.com). Reports are handled privately.

This code is adapted in spirit from the Contributor Covenant (https://www.contributor-covenant.org).
